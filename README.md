# PNLink Engagement Dashboard

## Overview

The PNLink Engagement Dashboard is an internal analytics and decision-support interface designed to help teams understand how users interact with the PNLink platform.

Built around exported user data, the dashboard turns raw records into a clear operational view of activation, engagement, inactivity, outreach priorities, and data quality. Its purpose is to make large user populations easier to read, compare, and act on.

## What This Project Does

This project provides a visual environment for exploring PNLink user activity through:

- high-level KPIs for activation and engagement
- charts that highlight trends and distribution patterns
- segmented analysis by institute, country, continent, cluster, language, field of expertise, and email domain
- actionable tables that help identify inactive users, real problems, and follow-up opportunities
- detail popups that allow teams to move from summary figures to the underlying user lists

## Why It Matters

Managing a large network of users is not only about counting accounts. Teams also need to understand:

- who activated their account
- who stopped engaging
- where inactivity is concentrated
- which segments need targeted follow-up
- where the data itself may be incomplete or inconsistent

This dashboard helps answer those questions in a practical way, so that engagement efforts can be more focused, measurable, and effective.

## Main Value

The dashboard is meant to support both monitoring and action. It helps stakeholders:

- track adoption across the network
- identify user groups at risk of disengagement
- detect invitation and activation bottlenecks
- review data quality issues that affect reporting
- prepare follow-up lists for communication and support

## Intended Audience

This project is especially useful for:

- platform managers
- engagement and outreach teams
- institutional coordinators
- operational decision-makers
- anyone responsible for understanding PNLink usage across multiple user segments

## Project Scope

The PNLink Engagement Dashboard is not only a reporting screen. It is a management tool designed to transform exported platform data into a readable, actionable, and presentation-ready overview of network engagement.
